👤 使用者管理

同一台電腦可以建立多個使用者，作答進度互不干擾。

💡 想要在不同裝置間同步進度嗎？切換到該使用者後，到「📤 匯出 / 匯入」匯出 JSON 備份，到另一台裝置再匯入即可。

📤 匯出 / 匯入

使用者：— · 範圍：—
📋 或從剪貼簿貼上 JSON（適合用 LINE 訊息傳遞）
📱 行動裝置匯出建議：
· HTML 成績單／錯題講義 → 用「📲 系統分享」傳到 檔案 App、iCloud、Google Drive 或 Mail（LINE 聊天無法接收 HTML 檔）
· JSON 備份要透過 LINE 傳 → 改用「📋 複製到剪貼簿」貼成訊息，對方用本頁的「📋 從剪貼簿貼上 JSON」匯入

💡 跨裝置同步：在裝置 A 匯出 JSON 備份，透過雲端硬碟／Email 傳到裝置 B，再點「📥 匯入」即可還原。

📥 匯入語意：
· 完整還原：把使用者的進度整個換成備份檔當下的狀態（備份外的章節會被清空）。
· 僅匯入本卷（章節作答頁才會出現）：只還原本章節，其他章節不動。
· 任何模式都絕對不會動到「其他使用者」的資料。

各 App 接受度：
✓ 檔案 App / iCloud / Google Drive / AirDrop / Mail / LINE Keep：可收 HTML、JSON、CSV
✗ LINE 聊天 / Messenger / Instagram：不接受檔案 → 用「📋 複製到剪貼簿」貼成訊息
✗ LINE/FB 內建瀏覽器：點右上角「⋯」→「在 Safari／Chrome 開啟」再下載
